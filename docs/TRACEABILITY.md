# TZ → implementatsiya → tekshiruv

Holat sanasi: 2026-09-23. Manba: `Loyiha TZ.docx`, FR-01–FR-12 va kreativ funksiyalar. Foydalanuvchining keyingi topshirig‘i bilan asosiy backend NestJS, frontend React/Vite/TypeScript/Ant Design va ixtiyoriy OpenAI integratsiyasi tanlandi.

**Bajarilgan** kodning mavjud va ishlaydigan oqimini anglatadi. **Qisman** talabning faqat tekshirilgan qismini anglatadi. **Bloklangan** uchun zarur trained artifact, dataset yoki klinik dalil hali yo‘q.
